# TerraMow 实体说明

本文说明集成向 Home Assistant 添加的实体，以及它们何时显示未知或不可用。实体名称
来自集成的翻译文件，本文使用简体中文名称。

所有传感器和二元传感器都是诊断实体，Home Assistant 会把它们列在设备页面的“诊断”
分组；选择器和数值实体属于配置实体。

## 割草机

割草机实体支持启动、暂停和回充。活动状态（`docked`、`mowing`、`paused`、
`returning`、`error`）跟随机器人上报的任务状态。当前故障会使它显示 `error`
（见[事件与故障](#事件与故障)）。与机器人的连接失败或意外断开时，它也会显示 `error`，
直到连接恢复。属性 `back_to_station_reason` 说明返回基站的原因，`active_faults`
列出当前故障。

### 命令确认

启动、暂停、回充、分区割草和沿边割草命令会等待最多 5 秒，确认机器人返回了与本次命令匹配的
回复。设备拒绝时，Home Assistant 会显示错误；超时表示结果尚未确认，不会自动重发。
未提供命令回复的旧固件也会返回“未确认”。回复成功表示命令已接受，是否开始割草仍以
设备作业状态为准。

同一时间只确认一条命令，且两条命令至少相隔 1 秒，否则 Home Assistant 会报错。

### 分区割草

**分区选择**列出“全部分区”“沿边割草”和当前地图的各个分区。地图没有分区时，
“无分区可选”旁仍提供“沿边割草”；尚未收到地图前只显示“无分区可选”。选择某个分区
会开始割该分区，选择“沿边割草”会请求启动沿边作业，两者都等待设备确认。沿边割草要求
固件 `control` 版本至少为 8。选择“全部分区”只改变选项，不会向机器人发送命令；使用
割草机实体的“启动”命令开始全局割草。

## 事件与故障

**最近事件**显示机器人上报的最近一次事件码，属性包含事件时间和说明。**当前故障**在
设备明确报告无故障时为 `0`，有故障时显示编号最小的故障码，属性中包含全部当前故障。
收到设备反馈前两者都显示未知。

当前故障会使割草机显示 `error`，故障清除后恢复设备上报的作业状态；历史事件不会改变
当前故障状态。

## 任务状态

**任务**、**子任务**和**任务状态**分别显示机器人上报的当前任务、子任务和任务阶段。
状态使用 `mission_global_clean`、`sub_mission_wait_for_rain_to_stop` 等小写值，以便
Home Assistant 显示翻译，编写自动化时请使用这些值；`protocol_value` 属性保留设备
原始的大写枚举值。机器人上报了本版本集成不认识的值时显示未知。

这些传感器是只读的，不会向割草机发送控制命令。

## 当前会话

**当前会话面积**和**当前会话时间**显示机器人最近一次上报的作业已割面积和作业时长。
已割面积为零时，当前会话面积显示未知。

**当前会话进度**按已作业面积与总面积计算百分比，在设备报告作业完成前最高显示 98%，
只有完成时才显示 100%。机器人等待天亮时显示 0%。

进度不适用时，传感器不显示数值，而是未知：

- 尚未识别到完整地图、地图仍可建图，或尚未收到地图状态
- Spot 模式
- 划区或沿边割草
- 边建图边割草
- 机器人尚无作业可显示（从未作业或尚未收到作业数据）

新会话开始前，传感器保持设备最后一次上报的会话进度。Home Assistant 与机器人断开
连接时该传感器不可用。

## 地图

**地图状态**显示机器人没有地图、地图未完成或地图已完成，属性包含地图 ID、地图数量、
备份状态和主方向角度。**地图面积**以平方米为单位显示当前地图的面积。**作业模式**显示
当前作业的类型（全局作业、选区作业、划区作业或移动到目标点），选区作业时属性会列出
所选分区。这三个传感器在收到机器人上报的对应信息前显示未知。

三个二元传感器显示地图标志：**已识别地图**（机器人已识别到地图）、**可建图**（机器人
当前可以建图）和**正在备份地图**（正在备份或恢复地图）。它们在 Home Assistant 与机器人
断开连接时不可用，收到机器人上报的地图状态前显示未知。

**地图**摄像头绘制草坪地图（含分区和障碍物）、割草路径、基站，以及已知时的机器人
位置。相关数据见[地图与路径能力说明](developers/map_path.md)。
**纯地图**摄像头显示相同的地图图层，但不带外围信息面板和地图角标，适合嵌入仪表盘。

## 保养与计划

**刀盘剩余时间**和**基站清洁倒计时**以分钟为单位，从推荐保养周期开始倒数。属性显示
已使用时间、推荐周期，以及是否该保养（`needs_maintenance`）。**下次计划开始**显示
下一次计划作业的开始时间（HH:MM），没有计划时为未知。

## 割草设置

**割草高度**、**割草速度**和**主方向状态**传感器显示机器人上报的当前割草设置，可以用
下面的实体修改：

- **割草高度设置**、**边缘割草距离**和**割草间距设置**（毫米）
- **割草速度设置**：低速、中速、自适应高速，固件支持时增加自动模式
- **刀盘转速设置**：低速、中速、高速
- **主方向模式**：单主方向、多主方向、自动旋转主方向。角度实体（**单主方向角度**、
  **第一主方向角度**、**第二主方向角度**和**自动旋转角度间隔**，单位为度）只在对应
  模式下可用

设置会发送给机器人，但不等待回复，因此机器人没有应用某项设置时，Home Assistant
不会报错。

## 其他诊断

**电池**显示电量百分比，属性包含 `state`、`temperature`、`charger_connected` 和
`is_switch_on`。**充电状态**在机器人报告充电器已连接时为开。**电池温度状态**显示
设备上报的正常、过热或过冷等级；设备不提供摄氏度数值。断线时不可用，收到新的电池
状态前显示未知。**姿态**报告机器人的位置
和朝向：状态是 yaw，属性包含 `x`、`y`、`yaw`、`timestamp_ms` 和 `frame`。
**总割草时间**显示机器人上报的累计割草时间。**版本兼容性**比较机器人固件与本集成的
版本，属性 `message` 说明结果。
